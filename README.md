# Pidgeon examples

Agents that run, each in its own folder with its own README, dependencies and
`.env.example`. [Pidgeon](https://pidgeon.ai) is the email inbox API for AI
agents: it gives agents their own inboxes so they can work with emails just
like a human.

| Example | What it shows | Language | Run it |
| --- | --- | --- | --- |
| [`signup-agent`](signup-agent) | A browser agent signs itself up with an address it keeps, verifies with the code, and receives the password reset at the same address | Python, [Browser Use](https://docs.browser-use.com) | `./run.sh` |

Each one runs against production every day, so it works the way it reads.
